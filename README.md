# Cronograma PCP

Aplicação Flask para gerenciamento de projetos e cronograma em calendário (FullCalendar.js), com lógica de PCP para marcar tarefas atrasadas automaticamente.

## Como rodar

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Acesse http://127.0.0.1:5000
